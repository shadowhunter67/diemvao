# Vietnam Schools Directory

This public repository contains the runtime catalog needed for search, routing, and comparison. The working directory, rejected aliases, merge decisions, and canonicalization notes live in the private UniScoreVN data pipeline.

Public catalog entries intentionally keep only runtime fields such as id, name, short name, location, ownership, entity level, region, support status, capabilities, and public source links where available.

Run `npm run stats:coverage` to derive the current public coverage snapshot from the committed runtime registry.
