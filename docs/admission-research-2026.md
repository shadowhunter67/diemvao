# Admission Research 2026

UniScoreVN no longer publishes the full working research notebook in this repository.

The public app remains transparent about user-facing results:

- score-affecting formulas include official source links where available;
- unsupported methods are shown as unsupported instead of guessed;
- partial support is scoped to the exact inputs and rules that have been verified;
- catalog-only schools remain searchable/comparable but do not claim calculator support.

The detailed source-of-truth research, source conflict notes, reviewer decisions, and normalization workflow live in the private UniScoreVN data pipeline. Public runtime artifacts are generated from that pipeline and committed to this repository so the app can build without private access.

See [data-methodology.md](data-methodology.md) for the public methodology and [contributing-data.md](contributing-data.md) for reporting data issues.
